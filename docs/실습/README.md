# AIND Kiro 실습 커리큘럼

Spring Boot + MyBatis 기반 HR 프로젝트를 소재로, Kiro의 핵심 기능을 **기본 → 실무 활용 → 심화** 순서로 익히는 실습 과정입니다.

> 이 문서는 전체 실습의 목차이자 바로가기입니다. 각 실습은 순서대로 진행하는 것을 권장합니다.
> 처음 하는 분은 **반드시 [실습 ⓪ 시작하기](./00-시작하기.md)부터** 환경을 맞춘 뒤 ①~⑨를 차례로 따라가세요.

## 과정 구성

- **기본 (00~02)**: 환경 준비 → Steering(공통 규칙) → Specs(명세 주도 개발)
- **실무 활용 (03~06)**: 기능 추가 → 영향도 분석 → 코드 리뷰 → 버그 수정/회귀 테스트
- **심화 (07~08)**: 멀티에이전트 아키텍처 검토 → Hooks 자동화
- **참고 (09)**: 실무 적용 가이드와 FAQ

## 대상 프로젝트

- **백엔드**: Spring Boot 3.2.5 + MyBatis + MySQL (HR/근태 관리) — 소스 `src/main/java/com/aind/hr/`, 매퍼 `src/main/resources/mapper/`
- **프론트엔드**: React 19 + TypeScript + Vite SPA — `frontend/` (이미 구현되어 있으며, 실습 ②에서 이 결과물을 Spec으로 되짚어 봅니다)

## 처음 시작하는 분을 위한 안내

- 각 문서는 **① 목표 → ② 개념 → ③ 따라 하기(복붙 가능한 명령/프롬프트) → ④ 검증 → ⑤ 체크리스트 → ⑥ 흔한 에러** 순서로 구성됩니다.
- 코드 블록은 **그대로 복사해서 실행**할 수 있도록 작성했습니다. 실행 전 "어디서 실행하는지"(프로젝트 루트 / `frontend/` / Kiro 채팅)를 먼저 확인하세요.
- `> 💡` 는 실무 팁, `> ⚠️` 는 자주 틀리는 함정입니다.

## 공통 — "Kiro에 입력"이 무슨 뜻인가 (한 번만 읽어두기)

실습 문서에 "**Kiro 채팅에 입력**"이라고 나오면 아래를 뜻합니다. 실행 위치는 세 종류뿐입니다.

| 표기 | 어디서 실행하나 |
|------|-----------------|
| **Kiro 채팅에 입력** | Kiro의 채팅 입력창에 프롬프트를 붙여넣고 보냅니다 (IDE 우측 채팅 패널 또는 `kiro-cli chat`) |
| **터미널 / 프로젝트 루트에서** | 운영체제 터미널에서 `aind-hr-project` 폴더 기준으로 실행 |
| **`frontend/`에서** | 터미널에서 `cd frontend` 후 실행 |

**채팅에 파일을 넣을 때** `#파일경로`를 쓰면 그 파일이 대화 컨텍스트에 포함됩니다. 예: `#frontend/src/api/employees.ts`.

**에이전트 전환**(실습 ⑦에서 필요):
- IDE: 채팅 입력창 하단의 에이전트 드롭다운 → 원하는 에이전트 선택
- CLI: `kiro-cli chat --agent <이름>` (예: `--agent sa-orchestrator`)

> 💡 처음이라면 기본(Default) 에이전트로 ①~⑥·⑧을 진행하고, 에이전트 전환은 ⑦에서 처음 다룹니다.

## 중간 실습부터 보는 경우

실습은 순서대로 이어지며, 일부는 앞 실습 결과를 전제합니다.

| 실습 | 전제 |
|------|------|
| ③~⑥, ⑧ | 실습 ⓪의 백엔드 기동 + 초기 데이터 |
| ⑤ | 실습 ③의 검색 기능이 있으면 리뷰 대상이 풍부해짐 (없어도 기존 코드로 진행 가능) |
| ⑥ | 실습 ⓪ 백엔드. 검색 기능(③)과 무관하게 독립 진행 가능 |

> 전제가 없더라도 각 실습은 **기존 코드만으로** 핵심을 체험할 수 있게 작성했습니다.

## 사전 지식

Kiro의 기능(Steering, Spec, Agent, Skill, Hook)이 처음이라면, 각 실습 문서의 "개념" 절에서 그 기능만 필요한 만큼 설명하므로 별도 선행 학습 없이 바로 시작할 수 있습니다.
